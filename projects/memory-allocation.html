Memory Allocation Simulator

Developed as the final project requirement for CS 2101 (Operating Systems), the Memory Allocation Simulator is a Java-based Command Line Interface (CLI) application. Memory management is a highly abstract but critical component of computing architecture. This project translates complex textbook concepts into a practical, interactive tool, allowing users to visualize dynamic memory partitioning in real time and observe the internal fragmentation associated with core algorithms such as First-Fit, Best-Fit, and Worst-Fit.
